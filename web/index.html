    先创建一个分类

    分类是单据类型的容器（如「支票」），分类下再维护不同银行/版本的模板。 每个模板带自己的纸面参数（DPI、画布、纸张处理）和坐标清单。 上传时只要选「分类」，系统会按页自动识别每页属于分类下的哪个模板。

    创建分类

    分类是纯容器，不带纸面参数。建好分类后，再在分类下建具体模板（银行/版本）。

    创建模板

    模板 ID 由后台自动生成（形如 TPL20260925-0001）。

    画布 = 宽×高 像素 @ DPI。上传样张后会核对宽高比。
